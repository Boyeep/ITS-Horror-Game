# Setelah Jam Malam

## Mulai

Ekstrak seluruh ZIP, lalu buka `SetelahJamMalam.exe`. Game berjalan offline tanpa Python. Pilih Easy untuk perjalanan pertama. Cara main dapat dibuka dari menu utama maupun jeda.

Cerita dimulai dengan prolog. Arga sedang menyelesaikan proyek; Nara meninggalkan ponselnya sebelum menuju perpustakaan. Setelah listrik padam, ponsel itu menerima pesan dari pemiliknya sendiri. Ikuti tujuan di kiri atas, periksa objek bertanda, dan gunakan catatan untuk memecahkan puzzle. Save tersedia sepanjang perjalanan.

Mode Escape adalah sesi terpisah: cari dua sekring, tahan E pada panel, lalu berjalan melewati pintu keluar. Tiga monster menggunakan pandangan, pendengaran dan pola serangan berbeda. Berjalan pelan, pintu dan pengalih suara membantu memutus pengejaran.

## Kontrol

| Tombol | Tindakan |
| --- | --- |
| WASD / panah | Bergerak |
| Mouse | Arah senter dan lempar botol |
| Shift / Ctrl | Lari / pelan |
| E | Ambil, periksa, buka pintu, bicara, gunakan tangga |
| Tahan E | Panel atau konsol yang menampilkan progres |
| F / Q / M | Senter / botol / peta; peta tidak menjeda dunia |
| B / Tab | Buka tas; Tab di dalam tas mengganti kategori |
| Panah + Enter / X di tas | Pilih dan gunakan / letakkan satu barang |
| 1 / 2 / 3 / 4 | P3K / energi / alarm / lampu kimia |
| J | Catatan cerita |
| E / Enter / Space dalam dialog | Tampilkan seluruh kalimat; tekan lagi untuk lanjut |
| Angka + Enter | Masukkan sandi loker atau atur sakelar |
| Kiri / kanan + Enter | Atur dan konfirmasi frekuensi radio |
| F5 / F9 | Buka simpan / muat cerita |
| Esc / F11 | Jeda / layar penuh |
| Tab + Enter di menu | Pilih dan aktifkan tombol |
| Enter saat cutscene | Lewati; bisa juga melalui menu jeda → Lewati adegan |

## Bekal

HP awal 100. P3K memulihkan 40 HP; perban 20 HP. Item tidak dipakai jika HP penuh. Minuman memulihkan stamina dan memberi buff singkat. Lakban meredam langkah; alarm menarik perhatian setelah jeda; lampu kimia menerangi lokasi pemasangan. Botol pecah menimbulkan suara di tempat jatuh.

Tas memiliki 12 ruang dengan batas tumpukan. Barang penting seperti kunci, kartu dan bukti tersimpan terpisah serta tidak dapat dibuang. Membuka tas menjeda simulasi. Pencapaian tersimpan pada profil lokal dan tidak dibatalkan ketika memuat save.

## Save dan pengaturan

Tiga slot manual terpisah dari autosave. Muat mengembalikan progres, lokasi/lantai, HP, barang, pintu, puzzle, dialog dan waktu cutscene. Coba Lanjut cerita atau Muat permainan setelah membuka game kembali. Retry setelah kalah memberi HP penuh dan jeda aman.

Data berada di `%APPDATA%/ITS-Horror-Game/`: `settings.json`, `achievements.json`, dan folder `saves/`. Berkas `.bak` menyimpan cadangan save valid sebelumnya. Jangan menghapus folder ini saat memperbarui game; salin folder tersebut bila ingin membuat backup sendiri.

Volume efek dan musik terpisah. Volume efek juga mengatur blip percakapan. Pengaturan menyediakan brightness dan pengurangan efek gerak. Jika gagal berjalan, detail error tersimpan di `%TEMP%/ITS-Horror-Game-error.log`.

## Tentang latar

Game ini adalah fiksi yang terinspirasi kampus ITS. Foto/logo memiliki kredit tersendiri; ukuran tile, interior dan jaringan SIMPUL diadaptasi untuk permainan. Proyek ini bukan produk resmi ITS. Kredit komponen berada pada `THIRD_PARTY_NOTICES.md` dan folder `licenses` paket portable.
